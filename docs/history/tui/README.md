# TUI documentation (frozen)

**Status:** frozen since 2026-10-18. Bug fixes only; the TUI is rebuilt after the desktop
workbench covers the remaining workflows.

These files describe the terminal interface as it was before the desktop became the
interactive product surface. They are kept because the measurements and the interaction
decisions are still useful for the rebuild — not because the current UI matches them.

| File | Content |
|---|---|
| [`design.md`](design.md) | Layout, entry rendering, commands, panels |
| [`scroll.md`](scroll.md) | Follow mode, anchor, PgUp/PgDn and mouse wheel |
| [`attachments.md`](attachments.md) | `/attach` files and images, multimodal send |
| [`onboarding-plan.md`](onboarding-plan.md) | Onboarding flow plan |
| [`look.txt`](look.txt) | Reference snapshot of every view (text) |

Current interactive surface: [`../../features/desktop.md`](../../features/desktop.md).
