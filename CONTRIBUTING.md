# Contributing

Thanks for your interest in Rijoda Labs.

## Sign your work (DCO)

This project uses the **Developer Certificate of Origin (DCO)** instead of a CLA. Every commit must
carry a `Signed-off-by` line:

```
Signed-off-by: Your Name <you@example.com>
```

Add it automatically:

```bash
git commit -s
```

The full text is in [`DCO`](DCO). By signing off you certify that you have the right to submit the
contribution under this project's license.

## Workflow

1. Fork the repository, or create a branch if you have write access.
2. Keep commits small and focused. Use Conventional Commit prefixes: `feat:`, `fix:`, `docs:`,
   `chore:`, `refactor:`, `research:`, `adr:`.
3. **Language:** documentation in German, code, comments and commit messages in English.
4. Run the repository's checks before opening a pull request (tests, lint and any repo-specific
   check).
5. Open a pull request describing what changed and why.
